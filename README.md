# 🖼 Растерен редактор на изображения (конзолно приложение)
Студентски проект – реализиран с Java и OOP принципи

## 📌 Описание
Това е конзолно приложение за обработка на растерни изображения.  
Поддържат се операции за зареждане, трансформиране, управление на сесии и запис на резултати.

Проектът е реализиран с обектно-ориентирано програмиране и използва Command design pattern.

---

## 🚀 Функционалности

- Зареждане на изображения (`load`)
- Работа с множество сесии (`switch`)
- Добавяне на изображения към сесия (`add`)
- Трансформации върху изображения:
  - grayscale
  - monochrome
  - negative
  - rotate (left/right)
- Undo последна трансформация (`undo`)
- Създаване на колаж (`collage`)
- Запис на изображения (`save`)
- Запис с ново име (`save as`)
- Информация за сесията (`session info`)
- Помощна команда (`help`)
- Изход от програмата (`exit`)

---

## 🧠 Архитектура на проекта

Проектът използва:

- **Command Pattern** – всяка команда е отделен клас
- **Сесии** – поддържане на множество независими сесии
- **Трансформации** – реализирани чрез наследяване
- **Модулна структура** – разделение на логика по пакети

## 📸 Поддържани формати

- PPM – цветни изображения
- PGM – сиви изображения
- PBM – черно-бели изображения

---

## ⚠️ Важно

- Трансформациите се пазят в паметта до изпълнение на `save`
- Всяка сесия е независима
- Файловете се обработват чрез модел `ImageFile`
